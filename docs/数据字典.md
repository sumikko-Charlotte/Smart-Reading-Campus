## 脱敏规则

| 规则 | 对象 | 处理方式 | 处理前 | 处理后 | 说明 |
|---|---|---|---|---|---|
| R1 | 学号 / 读者号 | 加盐 HMAC-SHA256 后取前 16 位；盐值由校方或项目组保管，不随数据导出 | 2025211995 | u_7c1f9a2e5b3d08a4 | 同一学生在多次导出中保持一致，可跨表关联，但无法反推学号 |
| R2 | 姓名 | 不导出；如确需，保留姓氏 + 星号 | 万贝 | 万* | 证书展示所需姓名由系统内自行填报，不依赖校方数据 |
| R3 | 日期时间 | 统一截断到「日」，去掉时分秒；时区统一 +08:00 | 2026-03-12 09:41:22 | 2026-03-12 | 推荐只需要日粒度序列，精确到秒无必要 |
| R4 | 馆藏条码 | 如需可截断末 4 位，保留前缀以便区分复本 | B2023-004512 | B2023-0045** | 条码本身不含个人信息，可按需保留 |
| R5 | 借阅金额 / 罚款 | 不申请 | — | — | 涉及财务信息，与推荐目标无关 |
| R6 | 手机号 / 邮箱 / 身份证 / 成绩 / 家庭住址 / 生源地 | 不申请 | — | — | 与阅读推广目标无关，遵循最小必要原则 |

## 不申请的字段

| 字段 | 原因 |

| 手机号、邮箱 | 个人信息，推送走站内消息即可，不需外部联系方式 |

| 成绩、绩点、奖惩记录 | 与阅读推广无关，且可能造成不当关联 |
| 借阅罚款金额、欠款状态 | 财务信息，推荐场景不需要 |
| 家庭住址、生源地 | 敏感个人信息，最小必要原则下不采集 |
| 实时定位、设备信息 | 不在本项目采集范围 |
