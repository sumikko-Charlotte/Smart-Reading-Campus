## 第 2 条 · 学生名单 + 馆藏书目

```
一、学生名单（约 2 万条）

只要这 5 项：
· 学号
· 学院
· 专业
· 年级
· 班级（有就给，没有可跳过）

姓名、手机号、身份证这些都不要。

二、馆藏书目（约 10 万条）

必填：
· ISBN
· 书名
· 作者
· 出版社
· 出版年
· 中图法分类号（比如 TP181）
· 索书号
· 馆藏地（比如「沙河校区三层 A 区」）
· 馆藏复本数
· 可借复本数
· 历史累计借阅次数

有的话更好，没有可跳过：
· 页数、定价、目录、内容简介
```

## 第 3 条 · 借阅记录

```
三、借阅记录（2024 年 9 月至今，约 50 万条）

· 读者号（学号，脱敏方式我这边处理，见下一条）
· ISBN
· 借出日期
· 应还日期
· 归还日期
· 续借次数
· 借阅状态（在借 / 已还 / 逾期）
· 馆藏条码（可选，用来区分同一本书的不同复本）
```

## 第 4 条 · 脱敏与格式

```
关于学号

您直接导原始学号就行，脱敏我这边做。我拿到当天用脚本转成不可逆的哈希值，比如 2025211995 会变成 u_7c1f9a2e5b3d08a4，同一个学生在不同表里能对上，但没法反推回学号。转完原始文件当场删除，需要的话我可以写一份数据使用与销毁说明给学院备案。

明确不需要的字段

手机号、邮箱、身份证、照片、成绩绩点、借阅罚款、家庭住址、生源地——这些一律不要，跟推荐没关系，也能少占审批环节。

格式

· CSV 或 Excel 都行，UTF-8 编码
· 一个表一个文件，字段名放第一行
· 日期统一写成 2026-03-12 这种，不用带时分秒
· 借阅记录如果太大，可以按学年拆成两个文件

时间上不着急，您方便的时候安排就行，导出过程中有字段不清楚随时问我。
```
